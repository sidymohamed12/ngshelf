      Trois gestes, du catalogue à votre application

      1. Copier

        Chaque fichier se copie seul ou d’un coup, en Tailwind ou en CSS. Le code affiché est celui qui tourne dans l’aperçu.

      2. Régler

        Couleur d’action, rayon, densité, police : douze tokens habillent la pièce, en clair comme en sombre.

      3. Livrer

        Téléchargez le zip : le composant, son README et la licence MIT. Il ne dépend que d’Angular 22.

        Pourquoi ce catalogue existe

        Une interface accessible et soignée demande du temps. Beaucoup de bibliothèques ajoutent un paquet à installer, un compte à créer ou une version payante. Ici, chaque pièce est un fichier que vous lisez, gardez et modifiez.

        Gratuit
        Aucun paiement, aucune version « Pro », aucune limite d’usage.
        Open source
        Code sous licence MIT, utilisable dans un projet commercial. Gardez simplement la notice de licence.
        Sans compte
        Rien à créer, rien à installer : vous ouvrez une fiche et vous prenez le code.

        Pour les développeurs Angular qui ont mieux à faire que réécrire, une fois de plus, un calendrier accessible.

        Seul sur un projet client, en équipe produit ou en apprentissage : vous partez d’une pièce qui fonctionne, vous lisez son code, et vous gardez votre temps pour votre application.

        Ce que la pièce vous épargne
        L’accessibilité, le clavier, les libellés, le mode sombre : c’est déjà fait, relu et réglable.

        Contribuer

        Une ressource, c’est un dossier : ses fichiers, une démo et une fiche de description. Proposez-la par une demande de fusion sur GitHub ; elle est relue avant d’être publiée.

        Voir le dépôt sur GitHub Lire le guide de contribution

        Lien provisoire : le dépôt public n’est pas encore ouvert.
